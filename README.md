用户端 47 页，师傅端 32 页，管理端 37 页。用户端采用已确认的 4 个一级品类、17 个二级分类、89 个服务项目。

所有业务数据均为演示样本；支付、短信、AI 识别等未连接真实服务。页面内的交互仅保存在当前浏览器。

GitHub Pages 使用 `main` 分支的仓库根目录。直接更新 HTML、CSS、JavaScript 或图片并提交后，等待 Pages 完成发布即可。

本地预览：在仓库目录运行 `python3 -m http.server 8787`，然后访问 `http://localhost:8787/`。
